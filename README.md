# Ipl-Auction-dashboard

Developed an interactive Tableau dashboard to analyze IPL 2022–23 auction data and gain insights into player purchases and team spending.

Visualized team-wise spending to compare the budgets and auction strategies of different IPL teams.

Analyzed player roles, including batsmen, bowlers, wicketkeepers, and all-rounders, to understand player selection patterns.

Created visualizations to represent nationality distribution, comparing Indian and overseas players participating in the auction.
